#  PHYGO: Media Pembelajaran Interaktif Berbasis PWA pada Materi Kinematika Gerak Lurus dengan Pendekatan STEM

**PHYGO** adalah aplikasi media pembelajaran interaktif berbasis *Progressive Web App* (PWA) yang mengintegrasikan pendekatan **STEM** (*Science, Technology, Engineering, and Mathematics*). Aplikasi ini dirancang untuk membantu siswa memahami konsep dasar Kinematika Gerak Lurus melalui pembelajaran berbasis level, simulasi interaktif, kalkulasi rumus, dan tantangan soal.

---

## Fitur Utama

- **Progressive Web App (PWA):** Dapat diakses secara cepat melalui browser dan diinstal langsung di perangkat *mobile* maupun desktop.
- **Sistem Level Interaktif:** Jalur pembelajaran terstruktur untuk memandu progres belajar siswa.
- **Mode Survival:** Fitur evaluasi berbasis tantangan waktu untuk menguji kecepatan berpikir dan pemahaman konsep.
- **Pendekatan STEM:** Mengintegrasikan teori fisika, simulasi visual, serta kalkulasi matematika interaktif di setiap levelnya.
- **Konten Lengkap di Setiap Level:** 
  - 📖 **Materi Singkat & Rumus:** Penjelasan teori dasar fisika.
  - 🧮 **Perhitungan & Simulasi:** Simulasi visual interaktif untuk membuktikan persamaan fisika.
  - 📝 **Contoh Soal:** Latihan dan tantangan untuk menguji pemahaman.

---

## Alur Pembelajaran (Leveling)

1. **Lvl 1: Kecepatan Konstan (GLB)**
   - Pembahasan materi Gerak Lurus Beraturan (kecepatan tetap $v$).
   - Simulasi interaktif posisi terhadap waktu.
   - Contoh soal dan latihan GLB.

2. **Lvl 2: Percepatan Konstan (GLBB)**
   - Pembahasan materi Gerak Lurus Berubah Beraturan (percepatan $a$).
   - Simulasi perubahan kecepatan dan jarak.
   - Contoh soal dan latihan GLBB.

3. **Lvl 3: Gerak Jatuh Bebas (GJB)**
   - Pembahasan materi gerak akibat gravitasi bumi ($g$).
   - Simulasi objek jatuh dari ketinggian $h$.
   - Contoh soal dan latihan GJB.

---

## Teknologi yang Digunakan

Aplikasi ini dibangun menggunakan teknologi web murni tanpa *framework* tambahan:

- **JavaScript** – Logika simulasi interaktif, kalkulasi rumus fisika, dan sistem progres/level.
- **CSS** – Desain antarmuka (*UI/UX*) responsif dengan *dark mode theme*.
- **HTML** – Struktur halaman web dasar.
- **PWA (Service Worker & Manifest)** – Mendukung akses *offline* dan instalasi aplikasi.

---

## Cara Penggunaan Media

1. **Buka Aplikasi**  
   Pengguna diarahkan ke halaman Dashboard yang menampilkan progres belajar dan Peta Belajar tiga level.
2. **Pilih Level**  
   Pengguna memilih salah satu level pada Peta Belajar; level berikutnya terbuka setelah level sebelumnya tuntas.
3. **Pelajari Materi**  
   Membaca penjelasan konsep fisika beserta rumus terkait pada halaman Materi.
4. **Ikuti Simulasi**  
   Berinteraksi langsung dengan simulasi visual (gerak mobil atau benda jatuh) untuk memahami konsep secara praktik.
5. **Kerjakan Kuis Ujian Akhir**  
   Menjawab soal evaluasi dengan sistem nyawa; jawaban langsung diberi umpan balik.
6. **Level Tuntas**  
   Pengguna kembali ke Dashboard dengan progres terbaru dan level berikutnya otomatis terbuka.
